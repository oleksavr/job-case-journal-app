# job-case-journal-app
# Case Study — Local Work Journal

A private, local-first journal for documenting workplace cases and incidents.

## Open it

Double-click `index.html`.

Everything is saved in the browser's local storage. There is no account or backend.

## Features

- Create cases with date, category, status, location, people, witnesses, and summary.
- Add a dated timeline entry for each event.
- Search and filter cases.
- Open, review, or closed status.
- Export one case or the complete journal as JSON.
- Blue folded-card visual style with responsive mouse parallax.

## Evidence habit

Write observable facts, exact words, dates, times, location, witnesses, and what you did next.

Keep official documents and photos separately.

Export the journal regularly so a browser reset does not erase your records.
